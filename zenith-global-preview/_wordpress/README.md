# Lightweight WordPress News theme

The `zenith-global-news` folder is an installable classic WordPress theme. It uses core posts, categories, featured images, pagination, search and the block editor. No page builder, external font, JavaScript framework or plugin is required.

## Installation once hosting is supplied

1. Install WordPress on PHP/database hosting at the chosen News URL. GitHub Pages cannot execute WordPress. A news subdomain is simplest while the school preview remains on GitHub Pages; a same-domain subdirectory needs host routing.
2. Zip the `zenith-global-news` folder and upload it under Appearance → Themes → Add New → Upload Theme, then activate.
3. Set the site title and timezone; add the supplied school wordmark under Appearance → Customize → Site Identity.
4. Under Appearance → Menus, create the nine approved navigation items, using full school page URLs and the real WordPress News URL. Assign School navigation.
5. Choose readable post permalinks, remove default demo content, and publish real school posts with optimized featured images. Use the core editor. Leave comments disabled unless the school will moderate them.
6. Replace the static preview’s News navigation URL with the confirmed WordPress URL when it is ready.

No WordPress installation has been connected or activated. The HTML News page and sample article are design previews only. Theme runtime validation requires the target WordPress installation.
